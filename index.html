Introduction

Programming Robot Arms: A Technical Tutorial

Programming Robot Arms

A hands-on technical guide to programming the Franka Emika Panda 7-DOF collaborative robot arm using Python and ROS 2. From fundamentals to a complete pick-and-place application.

You will simulate, analyze, and control a research-grade robot arm — the same hardware used in university labs and industrial research worldwide.

Target audience: High school students with programming curiosity  ·  Written at undergraduate technical level  ·  All sources cited in IEEE format

About This Tutorial

Robot arms are at the frontier of automation, manufacturing, surgical assistance, and space exploration. Programming one requires integrating mechanical intuition, control theory, and software engineering — a rare combination that this tutorial develops step by step.

We use the Franka Emika Panda as our hardware reference. The Panda is a 7-degree-of-freedom collaborative robot arm with built-in torque sensing at every joint, making it one of the most capable and well-documented platforms available for education and research [1]. All software is open-source: ROS 2 [2], MoveIt 2 [3], and franka_ros2 [4].

Note: Every chapter begins in simulation (Gazebo + RViz). Chapter 9 covers the transition to real hardware. You can complete Chapters 1–8 and the capstone Chapter 10 entirely in simulation without a physical robot.

Prerequisites

You do not need prior robotics experience. Here is what helps:

Python basics Variables, functions, loops, and importing libraries (e.g., numpy).
High school math Trigonometry, vectors, and basic matrix multiplication.
Linux comfort Opening a terminal, running commands, editing files with a text editor.

Background material is provided in Appendix A for readers who want a refresher on ROS 2 concepts and Python patterns used throughout the tutorial.

How to Use This Tutorial

Chapters are designed to be read in order. Each chapter introduces vocabulary and code patterns that later chapters use without re-defining. If you skip ahead, cross-references will point you back to the relevant section.

Every chapter follows the same structure:

  1. Concept introduction — motivation and intuition before math or code.
  2. System diagram — a labeled diagram that the surrounding text explains.
  3. Technical depth — math, API details, and cited sources.
  4. Code example — a complete, runnable Python or bash script.
  5. Exercises — short tasks to test understanding.
Tip: Run every code example yourself. Understanding deepens dramatically when you observe the robot moving in response to code you typed.

A Note on Citations

This tutorial cites its sources in IEEE format, the same convention used in robotics journal papers and conference proceedings. When you see a superscript like [1], it refers to a numbered entry in the References section at the bottom of the page. Primary sources are always preferred: hardware datasheets, peer-reviewed papers, and official software documentation.
